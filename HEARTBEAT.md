# Heartbeat Tasks

When a heartbeat arrives during normal working hours, check whether AppIntoss project work changed today.

## AppIntoss daily summary

If there were AppIntoss planning/design/marketing/PM changes today and no daily summary has been posted yet, prepare a Slack-visible summary with:

1. 오늘 결정된 것
2. 오늘 변경된 기획
3. 오늘 변경된 디자인
4. 오늘 변경된 마케팅 방향
5. 새로 생긴 리스크
6. 내 결정이 필요한 항목
7. 내일 할 일

Stay quiet with HEARTBEAT_OK if nothing changed or if it is late night unless urgent.
